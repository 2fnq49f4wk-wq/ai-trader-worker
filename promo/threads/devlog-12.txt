깃허브랑 클라우드플레어 연결법

먼저 용어 정리
· 깃허브 = 내 코드를 올려두는 온라인 보관함
· 클라우드플레어 = 그 코드를 진짜 사이트로 인터넷에 띄워 주는 곳 (작은 사이트는 무료)
· 연결하면 = 보관함에 코드 올리는 순간 사이트가 알아서 새 버전으로 바뀜

1. 클라우드플레어 가입 → 왼쪽 메뉴 Workers 들어가기. 서버 컴퓨터 따로 안 사도 됨
2. 클라우드플레어에서 "열쇠" 만들기
   내 프로필 → API 토큰 → 토큰 만들기 → "Edit Cloudflare Workers" 골라서 만들면 긴 문자열 하나 나옴. 이게 깃허브가 내 대신 사이트를 바꿀 수 있게 해주는 열쇠. 계정 ID 도 같이 복사
3. 열쇠를 깃허브 "비밀 금고"에 넣기
   깃허브 저장소 → Settings → Secrets and variables → Actions → New 로 열쇠랑 계정 ID 두 개 저장. 코드 안에 열쇠를 그냥 적으면 남이 보고 내 사이트를 맘대로 바꿀 수 있어서 꼭 금고에 넣어야 함
4. 사이트 설정 파일 하나 만들기 (wrangler.toml)
   사이트 이름, 처음 실행할 파일, 주소 정도만 적는 짧은 메모장 같은 파일
5. "자동 순서표" 만들기 (.github/workflows 폴더 안 파일)
   "코드 올라오면 → 검사 → 통과하면 클라우드플레어에 배포" 이 순서를 적어두면 깃허브가 매번 알아서 해줌
6. 끝. 이제 코드 올리면 1~4분 뒤 사이트가 바뀜. 검사에서 걸리면 배포가 멈춰서 고장 난 버전은 안 올라감

나는 4, 5번 파일은 클로드 코드한테 "깃허브에 올리면 클라우드플레어로 자동 배포되게 해줘" 한 마디로 만들게 했고, 열쇠 만들고 금고에 넣는 것만 직접 함
