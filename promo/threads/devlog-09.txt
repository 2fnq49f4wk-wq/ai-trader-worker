아직도 클로드를 채팅으로만 쓰는 사람 손해 보는 중임

1. 클로드는 3종류임. Chat, Cowork, Code. 다 다른 물건임
2. Chat은 우리가 아는 그거. 공부, 요약, 수행평가 자료조사할 때 씀
3. Cowork는 내 컴퓨터 폴더를 직접 만지면서 일을 알아서 함. 자료 정리, 엑셀, 보고서. 코딩 몰라도 됨
4. Code는 진짜 개발용. 말로 시키면 코드 짜고 실행하고 깃허브에 올리고 배포까지 함
5. 고딩 기준 추천은 아이디어는 Chat, 귀찮은 정리는 Cowork, 진짜 만드는 건 Code
6. 나는 Code로 모의투자 사이트까지 만들었음ㅋㅋㅋ 코딩 잘 못해도 됨
