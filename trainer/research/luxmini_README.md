# LUX-Mini — 브라우저에서 도는 작은 주식 판단 모델 (결과 노트)

## 무엇인가
- 단기(5거래일) · 중기(20거래일) · 장기(120거래일) × 한국·미국 = 머리 6개. 머리마다 LightGBM 얕은 나무(깊이 ≤ 3 · 잎 ≤ 8 · ≤ 64그루).
- 가중치 `public/luxmini.json` 125KB(gzip 약 35KB) · 추론 `public/luxmini.js` — 보는 사람 브라우저에서 계산(Worker CPU·D1·요청 0, 정적 파일 1회).
- 입력: `/api/state` watchlist 가 이미 보내는 필드만 — price(시간외면 regPrice)·prevClose·dayPct(시간외면 regPct)·rsi·ma·dailyMaShort·ma50·atr·bbLower/bbUpper·return5/20/60·ret1y.
  시장 맥락(상승 종목 비율·종목 수익 중앙값)은 같은 시장 watchlist 로 화면이 센다. 학습 패널 종목 집합 = watchlist(한국 443/446 · 미국 552/558).
- 목표: h 거래일 뒤 수익이 같은 날 같은 시장 종목 **중앙값**을 넘는가.
- 출력: p(Platt 보정 후 그날 시장 평균 0.5 로 중심화) · 그날 시장 안 10분위 → 라벨(주의/약간 주의/중립/약간 긍정/긍정) ·
  ex(검증 구간 같은 10분위의 중앙값 대비 초과수익 중앙값·사분위) · 근거 3줄(Saabas 경로 기여 상위 3 + 학습 구간 그 값 10분위의 실제 승률, [한국어, 영어]).

## 방법 (walk-forward · 홀드아웃은 아무것도 고르지 않는다)
- 날짜 순: 학습 앞 60% → 검증 60~75%(조기 종료 · Platt · ex 표 · 특징 방식 선택) → 홀드아웃 뒤 25%. 구간 사이 h 일 엠바고.
  - 한국: 학습 2004-01~2017-03 · 검증 ~2020-10 · 홀드아웃 2020-10-20~2026-11-03
  - 미국: 학습 2005-03~2017-10 · 검증 ~2021-03 · 홀드아웃 2021-03-03~2026-11-02
- 지표: 날짜별 Spearman IC 평균 · 상위 10% 초과수익(같은 날 **동일가중 평균** 대비 − 왕복 비용 KR 0.30% / US 0.10%, 보유기간마다 1회)
  · t = 2h 거래일 날짜 블록 평균의 t(겹치는 라벨 자기상관 차단). 기준선 = 60일 수익 순위(모멘텀) · 무작위.
- usable(화면 '검증 통과') = 홀드아웃 IC t ≥ 2 **그리고** (IC − 모멘텀 IC) t ≥ 2 **그리고** 상위 10% 순초과 > 0. 나머지는 '참고(검증 미달)'.
- 특징 방식: raw(원값 + 시장 맥락) vs pct(같은 날 시장 안 백분위). **검증 구간 IC 평균**으로 골랐다: raw 0.0279 vs pct 0.0271 → raw.

## 솔직한 한계
- 신호가 약하다: AUC 0.51~0.53. 순위(IC)는 모멘텀보다 확실히 낫지만(단·중기는 모멘텀이 오히려 역방향), 한 종목 확률로는 거의 동전이다.
  화면은 '확률' 보다 '시장 안 10분위' 와 근거 문장을 앞세우는 게 맞다.
- 장기(120일) 머리는 상위 10% 성과가 단순 60일 모멘텀보다 크게 못하다 — 두 시장 모두 '참고'.
- 생존 편향: 유니버스가 오늘의 구성 종목이다(상장폐지 종목 없음). 초과수익 절대값은 부풀려졌을 수 있다(순위 비교는 덜 영향).
- 지수 대신 유니버스 중앙값을 시장으로 쓴다. 장중 값(dayPct·price)은 종가 기준으로 학습했다 — 장중 판단은 덜 정확하다.
- 개발 중 1차 시험의 상위 10% 지표가 '중앙값 대비' 라 무작위도 + 로 나와 '동일가중 평균 대비' 로 고쳤고, usable 문턱을
  과제 정의대로 '기준선 대비 t ≥ 2' 로 엄격하게 바꿨다(1차 판정보다 usable 이 줄었다 — 느슨해진 방향의 변경은 없다).
  특징 방식(raw/pct) 두 판의 홀드아웃을 모두 봤지만, 선택은 미리 정한 검증 IC 규칙으로만 했다.
- 재무(실적·PER)·뉴스 없음. 투자 권유가 아니다.
