# 대시보드 원본 백업

대시보드(`public/index.html`)를 크게 손대기 전의 **원본 스냅샷**을 여기에 보관한다.
바꾼 게 마음에 안 들면 아래 명령 한 줄로 그대로 되돌릴 수 있다.

| 파일 | 시점 | 내용 |
|---|---|---|
| `index.V32.70.html` | V32.70 (2026-07-27) | AI 두뇌 실시간 스캔·판정 시각화 / 우측 사이드바 / 터미널 밀도 레이어를 넣기 **직전** 원본 |

## 되돌리기

```bash
# 전체 원복 (V32.70 상태로)
cp backup/index.V32.70.html public/index.html
git commit -am "revert: 대시보드 V32.70 원본으로 원복"
git push origin main
```

부분 원복(터미널 밀도만 끄기 등)은 화면에서도 가능하다 —
우측 사이드바 헤더의 `▮` 버튼이 터미널 밀도 레이어 on/off,
`❯` 버튼이 우측 사이드바 자체 접기다. 설정은 브라우저에 저장된다.

> 참고: git 히스토리에도 남아 있으므로 `git show 100595a:public/index.html` 로도 원본을 꺼낼 수 있다.
> 이 폴더는 "명령어를 몰라도 파일 하나 복사로 끝나게" 두는 용도다.
