# Codex V33.329 — 매매 경로와 신규 모델 검증 감사

기준: main f8251c4(V33.328), 2026-09-09. 모델 아키텍처·주문 한도·손절·검증 문턱은 변경하지 않았다.

## 확인된 결함과 수정

1. AI_PRIMARY 분기가 독립적으로 평가한 scalp 후보까지 지웠다. 이제 scalp 후보는 보존한다. swing AI 후보는 기존 위원회·메타 게이트를 계속 통과해야 한다.
2. snap 선택이 `_uptrend`의 RSI >=45와 별도 RSI <=45를 동시에 요구했다. 두 조건의 교집합은 정확히45뿐이었다. 이제 기존 `evaluateEntry`가 reversal·snapEdge·국면·기대값·자가치유 검사를 마친 snap 셋업을 재사용한다. trend가 가득 찼다고 snap으로 바꾸지 않는다. 실제 선택 셋업은 포지션 `meta.aiSetup`에 남긴다. 이는 수익 개선의 입증이 아니라 잘못된 경로 수정이다.
3. 전진 검증의 `id+ts` 조회가 ID 고수위를 갱신하지 않았다. 같은 표본을 다음 실행에서 다시 합산할 수 있었다. ID 커서를 갱신하며, ID 커서가 없는 해당 구판 원장은 중복 배제를 증명할 수 없어 재측정한다. 모델 가중치는 삭제하지 않는다.
4. `keepDays:45`가 원장 행 개수만 제한했다. 새 표본이 없을 때도 실제 45일이 지난 증거는 만료한다. 충분하지 않은 배치는 이전처럼 대기시켜 다음 배치와 합친다.

## 신규 모델이 모두 정식 합류하지 않는 이유

초기 live 응답에서 DNN/GBDT/XGB/LGB/CAT은 정식, SEQ는 잠정이었다. FLOW/XALPHA/STACK/DUAL은 관측 기간 부족, MEMO는 성능 미달이었다. 모두 같은 원인이 아니다.

V33.326의 달력 홀드아웃 수정 이후에도 과거 학습 레코드는 자동으로 바뀌지 않는다. FLOW를 현재 main으로 실제 재학습했다(GitHub Actions run 34363716458, success). 홀드아웃이21일/유효2블록에서70일/7블록으로 늘었지만 t=0.448로 기준에 미달했다. 따라서 pending이 reject로 바뀐 것은 검증이 실행된 결과이며, 정식 합류로 강제 변경할 근거가 아니다. 이후 학습 결과는 AI_HANDOFF에 기록한다.

전진 검증은 학습 집합과 배타적이고 관측시각도 이후인 표본을 요구한다. 재학습을 여러 번 실행해도 독립 거래일3일이 즉시 생기지 않는다. 구판 중복 가능 통계를 제거하면 표시 표본이 줄 수 있다.

## 모델 교체와 수익 개선에 필요한 다음 증거

- 기존 학습기는 선형/트리/MLP 후보 및 기존 국면·기대값 기반 전략 선택 경로를 갖고 있다. 더 큰 신경망으로 바꾼다는 이유만으로 우월성이 입증되지는 않는다.
- 이번 라우팅 변경 전후를 동일 기간·시장·비용·슬리피지 조건에서 비교해야 한다. 거래 수, 비용 차감 기대수익, 최대 낙폭, 회전율과 국면별 성과를 함께 본다. 실제 장중/장기 성과는 이번 배포 시점에 알 수 없다.
- 모델 교체 후보는 누수 없는 시간순 홀드아웃과 독립 전진 표본에서 기존 모델보다 낫다는 증거가 필요하다. 실패할 때 문턱을 낮추거나 합류 라벨만 바꾸지 않는다.
- US/KR 금액을 통화 변환 없이 합친 수익계수는 해석하지 않는다. 기존 API의 시장별/수익률 기반 지표를 사용한다.
- 여러 전략 중 가장 잘 나온 것만 반복 선택하면 과최적화 위험이 있다. 후보 선택과 최종 평가는 분리해야 한다. 참고: [Bailey et al., Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf), [FINRA algorithmic trading testing guidance](https://www.finra.org/industry/notices/15-09).

## 디자인/검증 범위

요청한 시각화·디자인 스킬에 따라 관측 목적을 '모델 합류 병목 비교'로 좁혔다. 기존 구조 관측 탭에 흑백 검증 카드, 서버 판정 사유, 실제 지분과 전진 표본/날짜 기준을 제공한다. 작동/연구 탭·사이드바·다른 페이지 배치는 바꾸지 않는다. 기존 ai-mode 응답만 사용하고 추가 요청/타이머는 없다. 키 기반 DOM 갱신으로 펼침 상태와 초점을 보존한다. 모든 원격 문자열은 textContent로 넣는다.

새 실행 회귀검사 `tools/check-forward-route.mjs`: ID+관측시각 모드, 동일 표본 반복조회, 소배치 보존, 구판 원장 재측정, 기간 만료, 전략 버킷·활성 조건, scalp 경로 보존. 배포 워크플로에 배선했다.
