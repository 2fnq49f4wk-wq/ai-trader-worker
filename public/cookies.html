쿠키 · 저장소 정책

시행일 2026-11-02 · 버전 2026-11-02

쿠키를 쓰지 않습니다. 광고·분석·추적 쿠키, 광고 SDK, 분석 SDK(구글 애널리틱스 등)를 넣지 않았습니다. 서비스가 동작하는 데 꼭 필요한 값만 이 기기의 브라우저 저장소(localStorage)에 둡니다 — 이 값은 서버로 자동 전송되지 않습니다.

1. 필수 저장소(거부하면 서비스가 동작하지 않음)

이름용도기간
lux-uid이 기기의 무작위 코드(내 MY 데이터를 여는 열쇠 · 서버에는 해시로만 저장)로그아웃·삭제 전까지
lux-auth · lux-auth-ts로그인한 닉네임 · 가입 시각(로그인 상태 유지)로그아웃 전까지
lux-profMY 데이터의 기기 사본(빠른 화면 표시)로그아웃·삭제 전까지
lux-consent이 동의 선택 기록다시 고르기 전까지
서비스 워커 캐시화면 파일을 기기에 보관해 빨리 열기(앱 설치·오프라인)새 판이 나오면 교체

2. 화면 설정 저장소(편의 · 기기에만)

luxTheme(밝게·어둡게) · lux-lang(언어) · luxPage(마지막 화면) · luxDensity · luxRailTab · luxRailSyms · luxPzOpen · luxIntroDay · priceAlerts(가격 알림 조건) · luxLiveCache · luxAiModeCache · bootBundle(화면 빠른 시작용 사본) · luxPush(알림 켬 여부). 모두 이 기기에만 있고 서버로 보내지 않습니다.

3. 선택 항목(동의 배너에서 고름)

항목내용거부 시
외부 글꼴(Google Fonts)제목·숫자용 글꼴 4종을 Google 서버에서 받습니다 — 이때 접속 IP·브라우저 정보가 Google 에 전달됩니다.기기에 있는 시스템 글꼴로 보입니다(기능 차이 없음)
화면 성능 진단화면이 멈춘 시간·화면 이름·브라우저 종류를 익명으로 보냅니다(동의한 기기 중 5%만).보내지 않습니다

4. 외부 SDK · 외부 요청 점검 결과 (2026-11-02)

  • 광고 SDK · 분석 SDK · 소셜 로그인 SDK · 결제 SDK: 없음
  • 화면이 직접 연결하는 외부 주소: fonts.googleapis.com · fonts.gstatic.com(위 선택 항목 · 거부 가능)뿐
  • 시세·공시 원천(Yahoo · Nasdaq · SEC · 네이버)은 서버가 받아 오며 이용자의 기기는 직접 접속하지 않습니다(IR 원문 링크를 누른 경우 제외).
